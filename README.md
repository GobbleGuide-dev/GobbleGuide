## 🔍 About Gobble Guide

Gobble Guide is a user-generated content (UGC) recipe sharing app designed to help users:

- Create and share unique recipes  
- Save meals for weekly planning  
- Discover new dishes from the community  
- Follow other creators  
- Build a personalized cooking journey  

This repository ensures that users, contributors, and reviewers always have access to up-to-date documentation.
